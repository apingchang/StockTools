> 適用版本：v0.9.3-HOTFIX（2026-06-08）
> 開發環境：Python 3.8+ / Windows 11 / PyCharm
> GitHub：https://github.com/apingchang/StockTools（分支 `V0.9.3`）

## 一、這支在做什麼

台股量化選股 + 回測工具，**一支 Python 檔**就做完：

| 步驟 | 做什麼 | 資料來源 |
|---|---|---|
| 1 | 抓全市場每日收盤價 | TWSE / TPEx 公開 API |
| 2 | 抓最新月營收 | mops 公開 API |
| 3 | 抓最新 EPS 季報 | mops 公開 API |
| 4 | 算 PE / 殖利率 | 算的 |
| 5 | 用「簡易」或「多因子」評分排序 | 算的 |
| 6 | 取前 N 檔抓日 K 算技術指標 | TWSE 個股日 K |
| 7 | 事件驅動回測（進場/出場/持倉天數）| 算的 |
| 8 | 產出 Excel 報表 | openpyxl |

## 四、GUI 操作（四大區塊）

開啟後畫面分**左邊參數區** + **右邊 console**。

### 4.1 📊 基本參數
| 欄位 | 意義 | 預設 | 建議 |
|---|---|---|---|
| 選股檔數 (TopN) | 用幾檔去算技術面 | 60 | 30-100 視電腦效能 |
| 歷史月數 | 抓幾個月日K | 60 | 60-120 |
| 回測月數 | 用最近幾個月做回測 | 24 | 24-36 |
| 持股檔數 (TopK) | 同時持有幾檔 | 7 | 5-10 |

### 4.2 ⭐ 評分系統

兩種選一個：

#### 多因子評分（預設，進階）
```
Score = 動能1M × w1 + 動能3M × w3 + 動能6M × w6
      + 營收YoY × wR + EPS YoY × wE
```
預設權重：15% / 15% / 20% / 25% / 25%（總和 100%）
- **每個因子先 z-score 標準化**再加成
- 適合橫向比較大量股票
- 評分會受「當下市場行情」影響，波動大

#### 簡易評分（可調權重 + 門檻）
```
Score = 營收YoY × wR + EPS YoY × wE + 殖利率 × wD + PE × wP
```
預設權重：35% / 35% / 20% / -5%
- PE 給負權重 → PE 越低分數越高
- **有 4 個門檻**可調（點「⚙ 簡易評分進階設定」）：
  - 最低營收 YoY（%）
  - 最低 EPS YoY（%）
  - 最低 EPS（元）
  - 最高 PE（倍）
- **門檻啟用規則**：
  - 數值 = `-999` → **未啟用**（不過濾）
  - 數值 = `999`（PE 那個）→ **未啟用**
  - 其他值 → 啟用過濾

### 4.3 📈 技術指標
| 勾選 | 意義 |
|---|---|
| 多時間框架確認 (週線/月線) | 買點需週或月線至少一個確認 |
| RSI 背離檢測 | 排除熊市背離的買點 |
| 需要成交量過濾 | 買點當日量需 ≥ 20日均量 × 倍數 |
| 需要趨勢過濾 (站穩MA20) | 股價需站穩 MA20 |

**進階技術參數**：
| 欄位 | 預設 | 說明 |
|---|---|---|
| 成交量爆發倍數 | 2.0 | 2 倍以上才算爆量 |
| RSI 超賣門檻 | 40 | RSI < 40 視為超賣 |
| MA20 容忍度 | 1.0 (%) | 股價在 MA20 ±1% 內算站穩 |
| RSI 過熱出場 | 70 | RSI > 70 出場（exit_rsi）|

### 4.4 🔄 回測設定
| 欄位 | 預設 | 說明 |
|---|---|---|
| 停損 | -3% | 進場後虧 -3% 出場 |
| 停利 | +8% | 進場後賺 +8% 出場 |
| 最大持有天數 | 10 天 | 超過強制出場（時間出場）|
| 雙邊交易成本 | 0.4% | 進 + 出合計扣 0.4% |

### 4.5 🚀 模式切換
| 勾選 | 意義 |
|---|---|
| ☐ Top10 基本面回測 | 跳過技術面，直接做多 Score 前 10 檔，回測「選股能力」|
| ☐ Walk-forward 分析 | 分時段回測看穩定性（**注意：v0.9.3 不做樣本外驗證**，僅穩定性測試）|
| ☐ 使用 Excel 自選股 | 改讀 `stock_list.xlsx` 裡面的股票代號，不跑選股 |
| ☐ Excel 清單強制買點 | 把 Excel 股票的買點全部設 True（不過濾）|

3. 內容範例：

| 股票代號 |
|---|
| 2330 |
| 2454 |
| 2317 |

4. GUI 勾選 ☑ **使用 Excel 指定股票清單**
5. （選用）勾選 ☑ **Excel 清單強制買點模式**：跳過技術過濾
6. 按「執行策略」

### 6.1 一般模式工作表
| Sheet | 內容 |
|---|---|
| 選股結果 | 前 N 檔股票，含 Score/PE/殖利率/技術面 |

### 6.2 報表常用欄位速查
| 欄位 | 意義 |
|---|---|
| 股票代號 | 4-6 碼台股代號 |
| 公司名稱_來源 | 股票名稱 |
| 收盤價 | 當日收盤 |

| Score | 綜合分數（pd.NA = 未通過門檻）|
| 通過門檻 | True/False |

## 七、執行流程詳解

按下「執行策略」後的內部順序：

```
1. 抓股價（cache/price.xlsx）
2. 抓月營收（cache/revenue.xlsx）
3. 抓 EPS（cache/eps.xlsx）
4. 三表合併 → 算 PE、殖利率
5. 算評分
6. 取前 N 檔股票代號
7. 抓這 N 檔的歷史日 K（每檔 60 個月）
8. 算技術指標（MA/RSI/MACD/MTF/背離）
9. 判斷買點（多條件 AND）
10. 事件驅動回測
11. 寫 Excel
```

### 第一次跑會比較慢
- 60 檔 × 60 個月 = 3600 個月的日K要抓
- 預估 5-15 分鐘
- 之後用快取，只抓今天的股價，**30 秒內完成**

## 十、已知問題與限制

### 10.1 🔴 EPS YoY 年初失效（1-4 月）
**症狀**：1-4 月跑的 EPS YoY 全部是錯的，但不會報錯。
**原因**：mops 還沒公布最新一季財報，系統以為「最新」是去年 Q3，實際應 fallback 到「去年全年」對「前年全年」。
**影響**：1-4 月評分會偏低、選股會失準。
**暫時解法**：1-4 月用多因子評分（不依賴 EPS YoY 單一指標）。

### 10.2 🟡 Walk-forward 不做樣本外驗證
**症狀**：WF 結果看起來很穩，但因子權重沒有重新訓練。
**原因**：v0.9.3 沒實作 train 期網格搜尋 → 套到 test 期這段。
**影響**：WF 結果只能看「**時段穩定性**」，不能看「**樣本外泛化**」。
**暫時解法**：把它當成「分段回測」用，別當成「out-of-sample test」。

### 10.3 🟢 GUI 滾動
左邊參數區在小螢幕（< 1024 寬）需要滾動查看，這是 Tkinter 內建 canvas 行為，正常。

### 10.4 🟢 DEBUG 訊息太多
v0.9.3 為了解 bug 加了大量 `print()`，會洗版 console。**v1.0 規劃拿掉**。

## 十一、進階：手動跑回測（不開 GUI）

如果想做批次實驗，可以直接呼叫 `run_pipeline`：

```python
from StockTool import StrategyConfig, run_pipeline, GuiLogger
import queue

# 1. 載入 config
cfg = StrategyConfig()

# 2. 改參數
cfg.use_top10_backtest = True
cfg.topk = 5
cfg.stop_loss = -0.05
cfg.take_profit = 0.10

# 3. 跑
q = queue.Queue()
logger = GuiLogger(q)
run_pipeline(cfg, logger)

# 4. 印 log
while not q.empty():
    print(q.get())
```
